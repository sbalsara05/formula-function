# IMAGE_SOURCES

Attribution for self-hosted images added in the placeholder pass (`fix/fill-in-placeholders`).
No image here comes from Wikimedia/Wikipedia, WordPress CDNs or motorsport.com.

All files were fetched with `scripts/fill_placeholder_images.py`, resized to fit within 1400px and
re-encoded as JPEG (≤400KB). "Cropped" means a crop was applied before resizing; nothing else was altered.

Source order used: openly licensed Flickr photos (found via the Openverse API) first; official
formula1.com / FIA Formula 2 press imagery only where no usable openly licensed photo existed.
